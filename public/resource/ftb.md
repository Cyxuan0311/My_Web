# FTB — File Browser

> A terminal-based file browser, built with C++17 and FTXUI.

## Overview

FTB is a modern terminal file browser that brings a graphical file management experience to the command line. It allows you to navigate directories, preview files, and manage your filesystem entirely within the terminal.

## Key Features

- **Directory Navigation** — Browse files and folders with intuitive keybindings
- **File Preview** — Quick preview of text files directly in the terminal
- **File Operations** — Copy, move, rename, delete files with simple commands
- **Dual Pane** — Side-by-side directory view for efficient file management
- **Bookmark Support** — Save frequently accessed directories for quick access
- **Search** — Real-time file search within the current directory

## Technical Highlights

- Pure C++17 implementation with FTXUI for terminal UI
- Event-driven architecture for responsive keyboard and mouse input
- Asynchronous file system operations to prevent UI blocking
- Minimal memory footprint suitable for resource-constrained environments
