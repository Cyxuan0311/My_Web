# SPIDERS — News Crawler

> A Java-based news crawler application with Jsoup, Swing UI, and MySQL persistence.

## Overview

SPIDERS is a full-stack desktop application for crawling, storing, and browsing news articles. It demonstrates a complete Java application architecture with web scraping, database persistence, and a graphical user interface.

## Key Features

- **Web Scraping** — Jsoup-based HTML parsing for extracting news articles
- **Swing UI** — Desktop graphical interface for browsing and managing articles
- **MySQL Storage** — Persistent storage with structured article data
- **Scheduled Crawling** — Automatic crawling at configurable intervals
- **Search & Filter** — Full-text search and category filtering
- **Export** — Export articles to CSV, JSON, or HTML format

## Technical Highlights

- Maven project with proper dependency management
- JUnit test suite for scraping and data access layers
- Lombok for reducing boilerplate code
- JDBC connection pooling for efficient database access
- Multi-threaded crawling with configurable thread pool size
