# PNANA — Terminal Text Editor

> A modern terminal text editor built with FTXUI, inspired by Nano, Micro, and Sublime Text.

## Overview

PNANA is a feature-rich terminal text editor that brings a modern editing experience to your terminal. With 310+ stars on GitHub, it has gained recognition for its intuitive interface and powerful capabilities.

Built entirely in C++ with the FTXUI library, PNANA combines the familiarity of Nano's simplicity with the power of modern editors.

## Key Features

- **Intuitive UI** — Clean, well-organized interface with status bars and line numbers
- **Familiar Shortcuts** — Supports Ctrl-based keybindings similar to Nano and Micro
- **Syntax Highlighting** — Built-in syntax support for multiple programming languages
- **Multiple Buffers** — Edit several files simultaneously with tab switching
- **Search & Replace** — Full regex-powered search and replace functionality
- **Mouse Support** — Click navigation, selection, and scrolling via mouse
- **Unicode Support** — Full Unicode and UTF-8 support for international text

## Technical Highlights

- Written in modern C++17 with zero runtime dependencies beyond FTXUI
- Efficient memory management for handling files of any size
- Custom terminal rendering engine with double-buffering for flicker-free display
- Modular architecture separating UI, buffer management, and input handling
