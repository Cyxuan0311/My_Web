# Fcon — 3D File System Visualizer

> An interactive file system visualization teaching tool based on Vue3 + Three.js.

## Overview

Fcon transforms file system concepts into an interactive 3D experience. By representing files, directories, and permissions as visual 3D objects, it helps students and developers understand file system principles through exploration rather than memorization.

## Key Features

- **3D Visualization** — File system hierarchy rendered as an interactive 3D scene
- **Real-Time Navigation** — Click, zoom, and rotate to explore directory structures
- **Permission Visualization** — File permissions shown as color-coded visual indicators
- **Simulated Operations** — Create, delete, and move files with immediate visual feedback
- **Educational Mode** — Guided tours explaining core file system concepts
- **Export** — Save and share your file system visualizations

## Technical Highlights

- Vue 3 composition API with Three.js for 3D rendering
- Force-directed graph layout for organic directory tree visualization
- Reactivity system for real-time updates to the 3D scene
- Custom shaders for file type color coding and selection highlighting
